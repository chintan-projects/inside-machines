# Self-paced core, concrete repair

Utility: answer why generation needs the chosen token as new input; allow prediction when saved preparation is absent.

Usability: one operation per click, stable The/sky/is/blue identities, readable native labels, explicit chosen-versus-processed state. Do not turn the core into a matrix tutorial. A worked model stays reachable in the same example.

Desirability: warm paper, dark ink, restrained teal for prepared state and amber for newly chosen text. Space distinguishes the model, choice outside it and saved preparation. Color never carries state alone.

“I’m lost” opens help for the current beat. Topic aliases select prepared routes; ambiguity offers three related choices. Guided detail returns to the exact chapter/beat/cache state. Wrong diagnostic answers get specific feedback. No simulated AI chat, score-based access gate or stored private answers.

Responsive checks cover 390, 768 and 1440 pixels, all core beats, guided detail, keyboard, reduced motion, reset and cache replay. The cache-cleared replay removes preparation and the next choice before rebuilding. It never retains a processed successor while claiming work was cleared.

A narration-only critique is not a learner score. A passing product teach-back is not a narration pass. Human acceptance and real-phone testing remain independent.
