A prompt has six text pieces. The first answer piece has just been chosen. Before choosing again, how many positions must go through the whole model with saved preparation kept? And with it cleared?

This is a fixed, untrained two-layer toy, using two-number vectors and a five-token output list. Its scores are computed. It illustrates ordinary next-token generation, not a trained model’s language ability or measured GPU performance.

“The / sky / is / blue / and” are whole-word tokens in this toy. Real tokens may be parts of words. No AI calls happen during playback.
