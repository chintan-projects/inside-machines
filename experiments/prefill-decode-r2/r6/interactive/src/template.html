Read the complete explanation

This is a fixed, untrained teaching calculator with two layers, one number per piece and two candidates. Its simple sharing rule uses one plus a match’s positive part. Actual transformers use exponential sharing; the order of work and reusable data follow the same causal structure. Its numbers illustrate dependencies, not learned word meanings or measured speed. Real models use many learned numbers, more layers and additional operations.

Playback and the experiment make no AI calls. Follow-up conversation lives in your Claude Code or Codex session.

Sources and model scope

Hugging Face: caching and causal attention · Attention Is All You Need. The calculator uses a simplified positive-part sharing rule and one ReLU unit in each local update. It demonstrates causal data flow rather than literal GPT mathematics. It omits positional encoding and layer normalization and uses greedy selection. It does not cover speculative decoding or hardware bottlenecks.
