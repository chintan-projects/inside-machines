# Design brief and review contract
Person: A curious adult who has watched AI text stream but cannot trace what the model actually does.
Job: Follow one prompt into two generated tokens, then discover what caching changes.
Posture: patient, precise, tangible.
References: the owner's visual-learning.app/microwave example for one prominent mechanism and progressive guidance; the established Inside Machines native refrigerator path for shared core/depth controls and return to the whole. Borrow structure, not branding. Avoid the earlier tiny labeled vacuum postcard and crowded dropdown UI: it required effort before revealing a mechanism.
Tenets: The current operation gets most of the screen. A deeper view must return to the same example. A control earns its space by changing a causal quantity. Sound is an alternative way to follow, not a prerequisite. The exact toy computation is visible before a performance interpretation.
Tokens and rationale: warm white surface keeps the visual and prose together; dark ink gives strong contrast; blue=known prompt, gold=selected output, teal=reused K/V; labels and shapes carry the same meanings without color. Primary body and control text at least 16 CSS px on phone. Headers have a compact scale so the mechanism appears in the first journey. Motion only traces a dependency or a changed value; reduced-motion mode preserves all state changes.
Review method: desktop 1440, tablet 768, phone 390; inspect every core stage, depth controls, typed dive deeper, transfer answer conceal/reveal, reset, keyboard, reduced motion and offline behavior. Browser viewport simulation is engineering/craft evidence, not an actual-phone or real-learner pass. Record seen versus inferred findings in review/FRICTION.md. Owner sign-off remains pending.
