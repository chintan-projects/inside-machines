# Prefill and decode: series bible

## Audience and tone
Curious adult beginners (see plan.yaml). Calm blackboard tone (Theo); one running example, "The sky is → blue → and",
in every scene. No speed numbers, no hardware cutaways. Toy numbers are always called toy numbers.

## Concept colours
| Concept | Colour | Hex |
| --- | --- | --- |
| Prompt token (known input) | blue | #5B8DEF |
| Answer token (picked) | gold | #E0B04B |
| Key/value entry, KV cache | teal | #3FB5A3 |
| Active / made on this trip | yellow (HIGHLIGHT_COLOR) | scene_kit |
| Not allowed / rebuilt | red | #E06C5F |
| Structure (empty cells, arrows, labels) | grey | GREY_B / GREY_C |

The interactive uses the same roles on a paper ground with darker tints (prompt #2C5AA0, answer #A8741A, K/V #157067,
rebuilt #A73B32) so contrast passes on white.

## Recurring devices
- The board: columns are positions (1–5), rows are layer 1 (lower) and layer 2 (upper); input chips below, picked
  chips above. Every board state comes from `shared/lesson_states.json` (generated by `lesson/checkpoints.js`).
- Cell states: dashed grey = not processed; solid = processed; teal "K V" = keeps its key and value; yellow outline =
  made on this trip; red = rebuilt with the cache off.
- A picked token waits above the stack until it is fed back.

Cover: the board with three blue prompt chips and gold "blue" travelling back in; title "Why does AI write one token at a
