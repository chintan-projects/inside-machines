# Trusted AC context vector sources

These original SVG cutaways are authored source assets, derived from this project's
isometric primitives and AC hardware. They locate the four working components;
the CE lesson's separate bounded graphics demonstrate internal causal changes.
They contain no scripts, remote resources or model-supplied markup.

Both the interactive client and Python video renderer consume these exact sources.
The two files differ only in the room boundary, heat paths and corresponding labels.
They are schematic generic hardware, not an exact appliance or geometry-audit proof.
The source font is the bundled Inter face. Labels and opt-in motion follow ADR 0001.
