# Curated library and hosted framework integration

User decision: a curated initial library, free missing-topic requests, explicit
owner production, requester availability updates and per-system cost visibility.
Start with twenty generic systems rather than arbitrary customer-triggered AI.

## Prediction and decisions

The intended learner can follow input → working change → output and transfer that
cause to a changed condition. Each topic has a predefined misconception and rubric
in `design/lessons/curated/`. Hypothesis: four of five initially unfamiliar learners
score 2 on both causal explanation and transfer before hints. This is unmeasured.

The actual D1 player source moves into `web/studio`; local studies re-export it.
An adapter consumes safe versioned CE data. Domain geometry remains specific;
the player, media clock, path navigator, cache and private discussion remain shared.
All old packed study artifacts and published lesson/media hashes are preserved.

The more developed AC/washer/cooker/vacuum source remains in the trusted registry.
Sixteen additional cores add labeled sections, supported comparisons and final
relationship maps. These are implemented review drafts, not accepted physical art.
The earlier GPU and refrigerator experimental deep paths are preserved separately;
their quality or schema is not silently claimed for the added CE cores.

The owner can create a scoped depth draft with the parent's example, identity and
causal context, using the same reservation/checkpoints/provider routes. Depth
drafts do not replace their core or pretend to be new marketplace systems. They
must become real reviewed artifacts before release in a composed learning path.

## Observed engineering and browser findings

- Request subscriptions and notifications are private, transactional and idempotent.
  Member requests cannot dispatch paid work. Release is artifact/bundle bound;
  revocation removes the availability link while preserving inbox history.
- Owner path history is content addressed; compare-and-swap handles competing edits.
  Draft composition permits review before leaf approvals, while release stays held.
- Full-path offline downloads hash-check all media before one atomic cache commit.
  Active-node feedback/chat uses the right revision; failed navigation retains the
  prior scene. Idle tabs no longer erase another tab's newer paused checkpoint.
- Emulated 375/768/1440 layouts had no horizontal overflow. Keyboard seek/return,
  cold offline reload and reconnect were observed. Actual MP4 narration advances
  online and from saved blobs; pause/mute controls work. FFmpeg decodes audio/video
  with nonzero audio samples. This does not claim a human listening test.
- Mechanism review caught and corrected sealed-liquid compression, a false toilet
  trapway, rotation pivots and repeated GPU visuals. Tests verify actual geometry
  invariants, not just object shapes.
- Primary new car labels are about 15.2px in a 375px viewport. Supplemental map text
  remains small. The system map is explicit about its schematic role; most new art
  does not yet establish the selected trial's physical craft standard.
- The real heat-pump reunion narration measured 25.02 seconds including padding,
  exceeding the 25-second chapter contract. Rendering stopped before publication;
  fourteen verified checkpoints remained reusable. The headline was shortened
  without deleting a causal relationship; the source is rendered again rather
  than truncating audio or marking a failed artifact ready.

## Cost and release boundary

Seed rendering uses local computer speech and no new paid model calls. This is not
a unit-cost benchmark for generating a machine with Claude. The owner report
separates actual token receipts, estimates, uncertain billing, old revisions,
local provenance and unallocated costs. Hosting/storage and prior local study
spend remain separate. The app's $50 ceiling is preserved.

Gmail account/scope and connected Neon/private Blob ownership were reverified.
Claude's structured authoring adapter and key are configured for the personal
project; OpenAI research/review/chat/speech stay independently routed. No provider
comparison or automatic quality claim follows from an adapter contract test.

Required final test counts, artifact import, commit and deployment evidence will
be appended after verification. Independent technical, real-phone craft, beginner
learning and owner release remain held. BUG-004 remains open.
