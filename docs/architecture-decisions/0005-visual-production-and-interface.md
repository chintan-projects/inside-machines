# ADR 0005: hold visual production steady and design the learning interface

Date: 2026-10-20. Status: owner-selected direction; UI implementation for review.

The owner selected Claude plus the Anatomy visual production system after the
vacuum/GPU experiments. Stop comparing visual engines in this iteration. Use
Claude for visual authoring, the actual vendored Anatomy toolkit for appropriate
physical artwork, and the shared trusted player/domain rules for interaction.
Logical concepts retain appropriate logical representations under ADR 0003.
The selected pair is a production direction, not a claim that every existing
scene was authored by Claude or that arbitrary generated code is publishable.

Preserve the existing provider gateway, evidence/review routes, reservations,
receipts and quality gates. This decision does not silently change the deployed
OpenAI routes, add paid calls, replace computer narration or configure an
unverified Claude research/speech capability. Production adoption follows the
provider contract; authoring and playback remain distinct responsibilities.

The next bounded iteration is the shared local learning interface. Design the
composition, navigation, action hierarchy, typography and responsive experience
around the approved working visual system. Use the GPU path to review a complete
journey. Preserve its artwork, causal rules, assessments and audio. Do not mutate
the original vacuum artifact or imply that a local UI is deployed on Vercel.

Follow the [interface brief](../../design/lessons/studio-interface.md), project
design tokens and design-quality render/review loop. Record observed usability
and inferred preference separately. An owner preference decision about the
interface remains distinct from technical truth and beginner-learning acceptance.
