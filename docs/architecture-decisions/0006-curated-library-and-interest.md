# ADR 0006: curate publication, accept requests without paid generation

Date: 2026-10-20. Status: owner-authorized implementation.

The owner requests production adoption of the shared learning framework and an
initial twenty-system library. A customer request expresses interest; it must
never enqueue a paid model job. The owner can triage demand and explicitly build
a draft through the existing budgeted pipeline. Existing member conversations,
immutable revisions, media and ledgers remain intact.

Reuse the D1 player and learning-path envelope in the hosted client. Adapt
validated CE-1 data through a trusted adapter; never serve generated JavaScript.
Keep the old artifact reader for historical references. Shared source is shared
between the authoring studies and hosted app, rather than copied UI implementations.
Versioned path resolution, media, offline state and private discussions bind to
the actual lesson revision. Absence of a deeper branch is stated honestly.

Persist deduplicated topic interest and member subscriptions using the existing
Store. Public projections reveal only the current member's subscriptions and
notifications; owner reports may aggregate demand. Owner availability links must
refer to a current release-approved revision. Notification creation and release
are in the same transaction, idempotent per topic/member/revision. No email service
or external message delivery is enabled by this decision.

The initial systems are individually scoped and sourced authored drafts. The
same library/teaching/media contracts and publication checks apply to each. Cost
records distinguish measured API usage, retained uncertain allowances, estimates
and local authored work. Zero paid calls is not zero production effort; hosting,
storage and review labor are separate. The existing $50 app ceiling remains.

Preparing the authored source batch uses no new paid API calls; local computer
speech itself has no speech API charge. This is not a claim of zero historical
model spend, zero external invoices or zero hosting/review effort. Optional hosted
speech estimates count the complete narration of the active served revision,
including its reunion chapter. Before import they use the full authored source,
including the four preserved lessons. The estimate uses 130 words/minute and the
configured rate, independently of the immutable accounting ledger.

Claude + Anatomy remains the chosen visual-authoring direction. Enabling a
production Claude route requires its actual structured-output adapter, rates,
reservations and contract checks; the local text-only trial is not such a route.
Research, editorial review, chat and speech stay explicit and retain their own
capabilities. No silent paid retry or fallback is permitted.
